# Release notes

1. Sections, in order: Highlights, Changes, Fixes, Known issues.
2. One line per change, starting with a verb in the past tense.
3. Version as `vMAJOR.MINOR.PATCH`; link the ticket for every fix.
4. No internal hostnames, account numbers or client names.
