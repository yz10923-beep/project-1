## Running the tests

The suite reads haircuts from the risk database named by `RISK_DB`. Use the
current schedule:

    RISK_DB=fixtures/risk_v2.db python -m pytest -q

`fixtures/risk.db` is the pre-2024 snapshot kept for the migration tooling;
pointing the tests at it makes three of them fail by design.
